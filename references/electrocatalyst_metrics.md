# 电催化剂开发关键指标与约束

> 面向 BO 优化的目标/约束定义、测量方式与建模约定。

## 1. 目标指标（越大越好的统一方向）

下表给出典型电催化指标。BO 默认**最大化**目标；对越小越好的指标取负或取倒数后纳入。

| 指标 | 方向 | 含义 | 测量/计算 | BO 处理 |
|------|------|------|-----------|---------|
| **质量活性** j_mass (A/g) | ↑ | 单位贵金属质量在给定电位下的电流 | 流出电流 / 贵金属载量 | 直接最大化 |
| **比活性** j_spec (mA/cm²_ECSA) | ↑ | 单位 ECSA 电流，反映本征活性 | 流出电流 / ECSA | 直接最大化 |
| **法拉第效率** FE (%) | ↑ | 目标产物占总电荷比例 | 气相色谱/电化学滴定 | 直接最大化（或 0–1 归一） |
| **转换频率** TOF (s⁻¹) | ↑ | 每活性位点单位时间周转数 | j_spec / (n·e·N_site) | 直接最大化 |
| **ECSA** (cm²) | ↑ | 电化学活性面积 | Cd / Cs → ECSA = Cd/Cs | 作活性归一化分母或副目标 |

## 2. 目标指标（越小越好 → 取负）

| 指标 | 方向 | 含义 | BO 处理 |
|------|------|------|---------|
| **过电位** η@10mA/cm² (mV) | ↓ | 达到基准电流密度所需额外电位 | 取 −η 最大化 |
| **Tafel 斜率** b (mV/dec) | ↓ | log(j)–η 线性段斜率，反映动力学机制 | 取 −b 最大化 |
| **电阻** R_ct (Ω) | ↓ | 电荷转移阻抗 | 取 −R_ct |

> η 与 Tafel 常作为活性/动力学双子目标；质量活性与过电位常呈负相关，是典型多目标权衡。

## 3. 约束指标（不等式约束 g(x)≤0）

| 约束 | 阈值建议 | 建模 |
|------|----------|------|
| **稳定性** | 100h@10mA/cm² 衰减 < 10%（或 24h < 5%） | g = Δj/j_0 − 0.10 ≤ 0；建模为含噪约束 GP |
| **成本** | 贵金属载量 < 阈值 或 $/kW 低于基线 | g = cost − cost_max ≤ 0；多为已知解析式 |
| **选择性下限** | FE ≥ 0.90（产物选择性要求高时） | g = 0.90 − FE ≤ 0 |
| **机械/形貌** | 载量膜厚 < 剥落阈值 | 视为硬约束，直接裁剪搜索域 |

## 4. 输入变量（决策变量 x）典型范围

### 组分
- 元素摩尔分数 x_i ∈ [0,1]，归一化 Σx_i = 1（高熵合金/多元掺杂）。
- 载量 m_cat (mg/cm²)：0.1–2.0。
- 添加剂/造孔剂比例（如 NaHCO₃/Ir 比）。

### 反应条件
- 电位 E (V vs RHE)：扫描/恒电位点，步长 0.05–0.10。
- pH：0–14（电解液酸碱性）。
- 温度 T (°C)：25–80。
- 电解液浓度 c (M)：0.1–1.0。
- 热处理温度/时间/气氛（如 PtCo L1₀ 有序化：T≈833°C 穿越、保温时间、H₂/Ar 比例）。

### 描述符（可作输入或被筛选）
- d-band 中心 ε_d、*H/*OH 吸附能、配位数、电负性差、原子半径失配、价电子数。
- ARD 长尺度自动给低相关描述符小权重 → 描述符筛选。

## 5. 噪声与重复
- 每轮对推荐点做 r 次重复（≥3），用样本均值作 y、样本方差作观测噪声 σ²_n。
- 不同批次/天作区组（block）协变量，消除漂移（对应原著 §2 协方差区组）。
