# 贝叶斯优化理论基础

> 理论来源：Roman Garnett, *Bayesian Optimization*, Cambridge University Press.
> 本文件为电催化场景适配的精炼理论手册，所有公式编号对应原著。

## 1. 优化问题的形式化（Ch.1）

对昂贵的目标函数 f: X → R，BO 在序列决策框架下逐步选择观测点以逼近全局最优：

- **观测模型** y = f(x) + ε，ε 为观测噪声（电催化中源于测量重复性、仪器漂移）。
- **优化策略** π：根据已观测数据 D = (x, y) 选择下一观测点 x_{n+1}。
- **终止**：预算耗尽或收敛判据触发。

贝叶斯方法：对 f 维护一个先验分布 p(f)，用数据做贝叶斯推断得到后验 p(f|D)，再基于后验的不确定性感知策略选择下一实验点。

## 2. 高斯过程代理模型（Ch.2–3）

### 2.1 定义
p(f) = GP(f; μ, K)，由均值函数 μ: X → R 与正半定协方差函数 K: X×X → R 确定：

- μ(x) = E[φ|x]（φ = f(x)）
- K(x, x') = cov[φ, φ'|x, x']  （式 2.1）

任意有限点集 x 的函数值 φ ~ N(μ, Σ)，Σ_ij = K(x_i, x_j)（Gram 矩阵）。

### 2.2 后验推断（含噪声）
观测 y ~ N(φ, N)（N 为噪声协方差）。后验 GP 的均值/方差（式 2.10）：

- μ_D(x) = μ(x) + κ(x, x)ᵀ [Σ + N]⁻¹ (y − μ(x))
- σ²_D(x) = K(x, x) − κ(x, x)ᵀ [Σ + N]⁻¹ κ(x, x)

**矩的直觉**（式 2.12，单点情形）：令 z = (y−m)/s 为测量 z 分数，ρ = corr[y, φ]，后验均值 = μ + σρz，后验标准差 = σ√(1−ρ²)。
- 完全独立测量（ρ=0）不改变先验；完全相关测量（|ρ|=1）把不确定性压为零。
- 惊人测量（大 |z|）引起更大均值移动；噪声大 → ρ 小 → 对极端观测打折。

### 2.3 协方差函数
- **平方指数核** K_SE = exp(−½ d²)  （式 3.12）— 无限可微，过于平滑。
- **Matérn 族**（d = |x−x'|）：
  - ν=1/2（指数核） K = exp(−d)  （式 3.11）— 连续但不可微，过粗糙。
  - ν=3/2  K = (1+√3 d) exp(−√3 d)  （式 3.13）— 一次可微。
  - ν=5/2  K = (1+√5 d + (5/3)d²) exp(−√5 d)  （式 3.14）— 二次可微。
- **推荐**：ν=5/2 是务实默认选择（原著 §3.3）。
- **ARD（自动相关性确定）**：每维独立长度尺度 ℓ_k（式 3.25），可自动筛除无关描述符。

## 3. 超参数推断（Ch.4）

对超参数 θ（长度尺度、输出尺度、噪声），用边缘似然做模型评估/选择：

log p(y|x,θ) = −½ [ (y−μ)ᵀ(Σ+N)⁻¹(y−μ) + log|Σ+N| + n log 2π ]  （式 4.8）

- 第一项 = 数据拟合（Mahalanobis 距离）。
- 第二项 = 复杂度惩罚（与先验支撑体积成正比）— **贝叶斯 Occam 剃刀**。
- 第三项 = 归一化。

**MAP 模型选择**（式 4.7）：θ_MAP = argmax p(θ|D) ∝ p(y|x,θ) p(θ)。
**模型平均**：对 θ 后验采样（MCMC 或超参数采样）求积分，缓解超参数过拟合。

> ⚠ 实践警示（原著 §10.7）：ARD-Matérn + MLE 超参数 + EI 的组合在频率主义意义下可被构造出失败例（Bull 2011；Locatelli 1997）。缓解：对输出尺度加宽先验/适度膨胀、做模型平均而非点估计、保留探索性。

## 4. 采集函数（Ch.7 策略 / Ch.8 计算）

设 τ* = 当前最佳观测值（incumbent），预测分布 N(μ_D, σ²_D)，z = (μ_D − τ*)/σ_D。

### 4.1 期望改进 EI
α_EI(x;D) = E[max(f(x) − τ*, 0)]。
**无噪声闭式解**（式 8.9）：
α_EI = (μ_D − τ*) Φ(z) + σ_D φ(z)
- 偏导 ∂α/∂μ = Φ(z) > 0，∂α/∂σ = φ(...) > 0 — 单调递增于均值与不确定度，自动平衡 **exploitation / exploration**。
- **有噪声**情形（§8.2）：用潜在目标 φ 的后验（信号分量），incumbent 取后验均值最大点；噪声大的点 ρ 小、EI 自动降低。
- 推导梯度可用于引导内层优化（式 8.6）。

### 4.2 改进概率 PI
α_PI(x;D,τ) = Pr[f(x) > τ | x, D]，τ = τ* + ξ（ξ 为期望改进裕度）。
无噪声 = 预测分布在 τ 处的互补 CDF：α_PI = 1 − Φ((τ−μ_D)/σ_D) = Φ(z_τ)（式 7.6/8.22）。
- 偏好安全点，对 ξ 敏感；EI 偏好高风险高回报点。

### 4.3 上置信界 UCB
α_UCB(x;D,β) = μ_D + β σ_D  （式 8.24/8.25，β = Φ⁻¹(置信度)）。
- β 为探索参数，越大越偏向探索。
- **PI–UCB 对偶**：固定 β 的 UCB 等价于固定某目标 τ(β) 的 PI，但 τ(β) 依赖数据、逐轮变化（§8.4）。
- 理论 regret 上界分析常用 UCB（§10.x）。

### 4.4 其他（可选）
- Knowledge Gradient（§7.4/8.6）：多步前瞻，适合有限预算/非平稳。
- 互信息/熵搜索（§7.6/8.8–8.9）：最大化关于全局最优 x* 的信息增益。
- Thompson 采样（§7.9/8.7）：从后验 GP 采样一条路径取其 argmax。

## 5. 采集函数的优化（Ch.9，§9.2）

x* = argmax_{x'∈X} α(x'; D)  （式 9.8）— α 普遍非凸，需通用全局优化。
- 典型选择：DIRECT、CMA-ES；或带梯度多点重启的 L-BFGS。
- **关键陷阱**：远离已观测点处协方差衰减 → 后验退化为先验 → 梯度消失（平坦区），高维尤甚（维度灾难）。
- 对策：在历史观测邻域投入更多搜索力；用 ARD 降维；用拟蒙特卡洛/MC 估计的 MC 采集函数（BoTorch 路线）。

## 6. 扩展（Ch.11）

### 6.1 约束优化（§11.2）
x* = argmax f(x) s.t. ∀m: g_m(x) ≤ 0；可行域 F = {x | g_m(x)≤0 ∀m}。
- 约束函数 g_m 可未知/含噪 → 与目标联合建模为多输出 GP；可行性概率作为采集函数乘性惩罚或约束 EI。
- 电催化映射：稳定性（降解率）、成本（贵金属载量/价格）作为不等式约束。

### 6.2 批量观测（§11.3）
每轮并行 q 个点 x = {x_1..x_q}，动作空间 A = X^q。
批量采集 α_1(x;D) = E[τ(D₁)|x,D] − τ(D)（式 11.7）。
- 同步（整批完成再设计下一批）/ 异步（单点完成即补）。
- 电催化映射：高通量三电极阵列、多通道电化学站可并行多个样品。

### 6.3 多目标优化（§11.7）
同时优化 {f_m}，无唯一最优 → 识别 **Pareto 前沿**。
- 支配：x'≺x 当 x 在所有目标不劣且至少一目标更优；Pareto 最优点 = 不被任何点支配。
- 常用策略：加权和标量化、EHVI（期望超体积改进）、ParEGO、MOBO/DGP。
- 电催化映射：活性（过电位/质量活性）vs 选择性（法拉第效率）vs 稳定性 vs 成本的多权衡。

## 7. 闭环流程（贯穿全书）
1. 初始设计（DoE：LHS/分式析因/中心点+重复+随机化）收集 n_0 点。
2. 拟合/更新 GP 代理（超参数 MAP 或采样平均）。
3. 选采集函数 → 全局优化得下一观测点（或一批）。
4. 执行实验 → 测得目标值（含重复以估噪声）→ 追加数据。
5. 收敛判据：incumbent 连续 K 轮无改进 / EI 量级 < ε / 预算耗尽。
6. 终端推荐：argmax μ_D（x），附置信区间与收敛曲线。
